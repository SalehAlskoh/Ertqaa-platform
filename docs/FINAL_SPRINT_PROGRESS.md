## نتائج الفحص

MariaDB 11.4.13 على3308، الاتصال سليم. جداول المجال15 موجودة، والجداول الأربعة الخاصة بالإعلانات والإشعارات فارغة في قاعدة المشروع. حُفظت بصمات كل الملفات الحالية المتتبعة وغير المتتبعة وبصمات صفوف الجداول وقيودها خارج Git قبل التنفيذ.

توجد Models للإعلانات والعلاقات فقط؛ لا Controllers/Policies/واجهات إعلانات قائمة. نظام الإشعارات قائم ويُعاد استخدامه. لا توجد إدارة مستقلة لحسابات الطلاب؛ الموجود طلاب المجموعة ومراجعة الطلبات والتسجيلات، وستعاد روابط التفاصيل الحالية.

الصفحة الرئيسية الحالية تحوّل إلى قائمة الكورسات؛ سيضاف قسم الإعلانات الأحدث إلى هذه الصفحة الفعلية مع حفظ التحويل والتصميم. APP_DEBUG مفعّل محليًا، وAPP_KEY موجود، وStorage قابل للكتابة؛ رابط public/storage غير موجود عند الفحص. هذه بيئة تطوير وليست إثبات جاهزية إنتاجية.

## عقد التنفيذ

- publication عبر published_at الحالي: مسودة NULL، منشور <=الوقت الحالي، وتاريخ مستقبلي غير مرئي للعامة. النشر من الواجهة فوري بساعة الخادم، وإلغاء النشر يعيد NULL دون حذف السجل أو الصورة القديمة.
- يستقبل author_user_id هوية الكاتب أولًا وهوية ناشر الانتقال الفعلي عند النشر؛ لا يوجد عمود مستقل لسجل كل المحررين/الناشرين، ولا يُدّعى وجود Audit History.
- الإعلان الطلابي يستهدف كورسًا أو مجموعة فقط. القراءة تعتمد على التسجيل النشط الحالي؛ المحاضر يقرأ نطاق مجموعاته دون إنشاء أو تعديل.
- لا حقل FK أو metadata للإعلان داخل notification_messages. سيُستخدم type المسموح نصيًا بعلامة `student_announcement:<id>`، ونص إشعار عام لا ينسخ العنوان أو المحتوى المحمي. يعاد التحقق من الصلاحية عند فتح الرابط. لا تغيير schema.
- النشر يقفل سجل الإعلان داخل Transaction؛ لا إشعار جديد عند إعادة نشر الحالة المنشورة نفسها أو تعديل المحتوى، ويجوز إشعار جديد عند انتقال حقيقي من غير منشور إلى منشور. المستلمون المميزون لقطة لحظة النشر وليست صلاحية قراءة دائمة.
- إدارة الطلاب قراءة فقط للمدير عبر Gate الحالية، وتشمل الحسابات متعددة الأدوار والمعطلة وتاريخ التسجيل دون تغيير الدور أو الحالة أو كلمة المرور.

الخطوة التالية: تنفيذ Phase A ثم B/C مع فحص المخطط الحالي، والبدء بمراجع Stitch والواجهات عبر مهارة frontend-design. التفاصيل الفنية للمراجعة المعزولة خارج المستودع في مجلد العمل المؤقت الخاص بهذه المهمة؛ لا أسرار في الوثائق.
