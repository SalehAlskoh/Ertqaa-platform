## طبقة البيانات المنفذة

- `DashboardDataService`: مؤشرات SQL، قوائم بحد 6 سجلات، وإشعارات بحد 5، مع Eager Loading.
- `TrainingGroupService`: مشاركة شروط السعة الحالية مع استعلام تجميعي؛ دون تغيير دورة التسجيل أو الحجز.
- `DashboardController` وأربعة GET Routes محمية ببوابات كل دور؛ توجيه `/dashboard` حسب الأولوية مع حفظ تعدد الأدوار وروابط العودة الداخلية الآمنة.
- اليوم المحلي `Africa/Tripoli` يُحوّل إلى مجال UTC نصف مفتوح `[بداية اليوم، بداية اليوم التالي)`.
- سجل التحصيل يعرض المبالغ الموثقة مع عملة كل مجموعة، بما فيها المنسحبة، دون جمع العملات أو احتساب ربح أو افتراض استرداد.

## تحقق البيانات — 2026-11-15

قاعدة فحص مستقلة بصلاحيات خاصة، دون تعديل `.env` أو سجلات المشروع. نُفذت Migrations الموجودة فيها فقط. نجحت 46 عملية تحقق تشغيلية: المقارنة المستقلة للأرقام، تعدد الحالات، نهاية الحجز الدقيقة والمنتهية، السعة 80%، الطالب المميز، استبعاد الانسحاب، حدود اليوم والسنة في طرابلس، خصوصية المجموعات والإشعارات، القوائم المحدودة والحالات الفارغة. لم يُنشأ أو يُشغّل PHPUnit أو Feature Tests.

استعلامات طبقة القراءة مع بيانات الفحص الكثيفة نسبيًا: Admin 34، Staff 25، Instructor 13، Student 27. لم تُضف قراءة العلاقات المعروضة أي استعلام آخر. لا تعتمد المؤشرات على جلب جميع السجلات إلى PHP.

المشكلة المعالجة: رفض MariaDB استخدام aliases العدّ مع `capacity` في HAVING؛ استُخدم استعلام فرعي ثم WHERE، دون تغيير SQL Mode أو هيكل قاعدة البيانات.

## تحقق HTTP وBlade النهائي المبدئي

- 174 تحقق HTTP ناجحًا: كل لوحة لدورها 200، والتقاطعات غير المصرح بها 403؛ الحساب متعدد الأدوار يصل إلى جميع لوحاته الفعلية والأولوية الافتراضية Admin ثم Staff ثم Instructor ثم Student.
- الضيف إلى Login، الحساب بلا دور 403، والحساب المعطل لا يدخل. المحاضر ممنوع من مجموعة محاضر آخر؛ الموظف لا يصل إلى إدارة الموظفين أو المحاضرين.
- حفظ رابط العودة الداخلي بما فيه query بمسافات مشفرة؛ رفض الروابط الخارجية و`//` والشرطة الخلفية ومحارف التحكم. العودة إلى وجهة لدور غير مملوك تبقى 403.
- جميع روابط GET المعروضة قابلة للفتح: Admin 39، Staff 30، Instructor 26، Student 24، بما فيها Sidebar والروابط التفصيلية في بيانات الفحص.
- القوالب الأربعة تعرض حالات فارغة سليمة، و0 استعلام DB أثناء عرض Blade بعد تحميل البيانات والعلاقات.
- آخر بناء ناجح يحتوي CSS النهائي للطالب: `npm run build`. يجري الآن التقييم البصري المستقل للطالب، ثم توثيق الفحوص النهائية والتقرير.
